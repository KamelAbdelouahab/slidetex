SlideTeX — aide

Équations LaTeX vectorielles et éditables pour PowerPoint 2016+, Microsoft 365 et PowerPoint sur le web.

Insérer

Accueil › Équation LaTeX. Tapez la formule (sans $), réglez taille et couleur, puis Insérer (ou Ctrl+Entrée).

Modifier

Cliquez une équation SlideTeX sur la diapo : sa source se charge dans le volet. Modifiez puis Mettre à jour — position, mise à l'échelle et ordre d'empilement sont conservés.

Moteurs

  • MathJax intégré : aucune installation, fonctionne hors ligne. Couvre le mode mathématique (AMS, mhchem, physics, cancel, …).
  • LaTeX local : vrai LaTeX (TeX Live ou MiKTeX + dvisvgm) via le serveur local npm start. Tous les paquets : TikZ, pgfplots, chemfig, tableaux…

Compatibilité

  • Microsoft 365 / PowerPoint 2021 / 2024 / Web / Mac : insertion SVG + édition.
  • PowerPoint 2016 / 2019 (licence perpétuelle) : insertion PNG (SVG selon version), pas de ré-édition automatique.
